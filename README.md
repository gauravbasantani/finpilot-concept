# Finpilot concept

An unofficial design concept by Gaurav Basantani ([gauravbasantani.com](https://gauravbasantani.com)): a review step where every number an AI agent drafts in a quarterly investment report links to its source line, and every mismatch says how sure the agent is, so the committee can trace the report. It is not affiliated with or endorsed by Finpilot. The foundation, fund and numbers in it are made up, and nothing here is investment advice. Live page: https://gauravbasantani.github.io/finpilot-concept/
