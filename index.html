Design concept · Quarterly report review

A report the committee can check

A review step for investment teams: every number the agent drafts links to the line it came from, and every mismatch says how sure the agent is.

Gaurav Basantani
gauravbasantani.com
1The problem

An agent can draft the quarterly report in minutes. But the committee will ask where each number came from, and one wrong figure costs trust in all of them.

2The idea

Link every number to its source line, flag the ones that don't match, and say why the agent thinks they differ.

3What changes

The analyst checks two flags instead of re-reading every statement, and sends a summary the committee can trace.
